About the project

Qrko is a simple, free tool for quickly creating a QR code for a web link, any text, a Wi-Fi login or a business card with your contact details.

Why this tool exists

Most QR code generators make you sign up, track how often your code is scanned, or ask you to subscribe after a few days so the code keeps working. This project does the opposite: create your code quickly, for free, without handing your details to anyone.

How it works

The entire code is generated in your browser using JavaScript. Whatever you type — a link, some text, a Wi-Fi password or contact details — is never sent anywhere and never stored. The tool runs entirely on your own device. The same goes for the QR code reader: the picture you add is read in your browser and is never uploaded.

The resulting code carries your data inside it. There is no redirect through someone else's domain that could stop working one day or record who scanned your code.

What people use it for

  • A Wi-Fi code for a café, guest house or home, so guests never have to type the password
  • A link to a menu, price list or website printed on a poster or flyer
  • A business card with your name, company and phone number, saved with a single scan
  • Short text such as opening hours or an order number
